# zk-scripts

A library of Python scripts that I use along with my Zettelkasten note taking
system to streamline information management.

### add-birthtime.py
Script to add the creation time (known as the birthtime or btime) of a file to
the file name. Useful for digital Zettelkastens as this can be used as an ID for
a given file when linking notes together.

### remap_frontmatter.py
Useful for remapping frontmatter to a unified system across notes of different
types. Takes in a template and eats the template while formatting all notes to
match this templating format.

### update-daily-notes.py
Used to create daily notes that I personally use for fast navigation of notes
across different eras of learning.
